Der einfache Weg — eine Aktion

Der Kurzbefehl öffnet nur diese Adresse. Die Web-App schickt den Link dann selbst ab. Keine Header, kein JSON — es gibt nichts falsch zu machen.

…
  1. Kurzbefehle öffnen → + → oben auf den Namen tippen → Rezept erfassen
  2. Auf ⓘ (oder das Info-Symbol) tippen und Bei Teilen-Blatt anzeigen einschalten
  3. Aktion „URL öffnen" hinzufügen (danach suchen)
  4. In das Adressfeld die Adresse von oben einfügen
  5. Ans Ende tippen und aus der Variablenleiste über der Tastatur Kurzbefehlseingabe wählen

Fertig sieht das Feld so aus: die Adresse, und direkt dahinter die blaue Variable. Steht dort das Wort „Kurzbefehlseingabe" als normaler Text, ist es keine Variable — dann antippen und aus der Leiste wählen.

Beim ersten Mal fragt die Web-App nach dem Token. Danach nie wieder — der geteilte Link wird dann sofort erfasst.

Der API-Weg — läuft im Hintergrund, aber mehr einzustellen

Hierbei öffnet sich kein Browserfenster. Dafür brauchst du Header und einen JSON-Anfragetext, und genau dort geht es meistens schief.
