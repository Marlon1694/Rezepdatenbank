Schritt für Schritt

  1. Kurzbefehle-App öffnen → + → oben auf den Namen tippen → Rezept erfassen
  2. ⓘ antippen → Bei Teilen-Blatt anzeigen einschalten. Darunter bei Teilen-Blatt-Typen alles abwählen außer URLs und Text.
  3. Aktion „Text" hinzufügen → die Basis-URL von oben einfügen
  4. Aktion „Inhalte von URL abrufen" hinzufügen:
    • URL: die Variable Text wählen, dann /api/jobs dahinter tippen
    • Methode auf POST stellen
    • Header: Name und Wert von oben
    • Anfragetext auf JSON stellen
    • Feld hinzufügen → Typ Text → Schlüssel url → als Wert Kurzbefehlseingabe aus der Variablenleiste wählen
  5. Aktion „Mitteilung anzeigen" → Text: Rezept wird verarbeitet …

Der häufigste Fehler steckt im letzten Punkt von Schritt 4: Steht dort das Wort „Kurzbefehlseingabe" als normaler Text statt als blaue Variable, kommt beim Server keine URL an. Antippen und aus der Leiste über der Tastatur wählen.
